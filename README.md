### Intelligence & Smart Behavior
- **AI Smart Analysis Engine** — Automatic weapon profiling (defensive, offensive, tactical, strategic)

- **Smart Recommendations** — Context-aware suggestions in Arabic and English
- **SWOT Analysis System** — Structured strategic assessment with version history and AI-assisted drafts
- **Behavior Correction** — Improved error handling, safe database rollbacks, organized session management

### Professional Design
- **Military-grade dark theme** with steel navy, cyan neon accents, modern typography

- **Modern iconography** — Professional SVG icons for all interface elements

## Architecture

```
ArmoryGi/
├── config.py                  # Central configuration (database, themes, cache)
├── main.py                    # Application entry point with embedded support
├── controllers/               # Business logic controllers
├── models/                    # Data models and ORM definitions
├── database/                  # SQLAlchemy database manager, schema, seed
├── views/                     # PyQt6 user interface components
├── dialogs/                   # Modal dialogs (add, settings, export)
├── utils/                     # Utilities (AI, theme, language, intelligence)
├── resources/                 # Icons, styles, translations, HTML/JS
└── tests/                     # Test suite
```
